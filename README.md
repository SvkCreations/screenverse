# SCREENVAULT — Your Cinema. One Destination.

A movie and TV discovery site (English, Hindi, Bengali). React + Vite, Supabase, OMDb, Gemini.
It does not host or stream any films or series.

## What it uses
| Service | Used for | Where the key lives |
|---|---|---|
| Supabase | Auth, watchlist, favourites, history, preferences, curated lists | URL + anon key in `.env` (safe to be public) |
| OMDb | Title details, IMDb rating and votes, cast names, poster | Supabase secret `OMDB_API_KEY` |
| Gemini | AI Cinema recommendations | Supabase secret `GEMINI_API_KEY` |
| YouTube Data API | Finding official trailers (cached in the `trailers` table) | Supabase secret `YOUTUBE_API_KEY` |

OMDb and Gemini keys are never in the frontend. The browser calls two Supabase Edge Functions
(`omdb-proxy`, `gemini-recommend`) which hold the keys.

## Setup
1. Node 18+. `npm install`
2. `cp .env.example .env` and fill in `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY`.
3. Supabase SQL Editor: run `supabase/schema.sql`, `supabase/seed_curated.sql`, `supabase/seed_upcoming.sql`, then `supabase/trailers.sql`.
4. Deploy the functions and set secrets:
   ```
   npx supabase login
   npx supabase link --project-ref YOUR_PROJECT_REF
   npx supabase secrets set OMDB_API_KEY=... GEMINI_API_KEY=... GEMINI_MODEL=gemini-3.8-flash YOUTUBE_API_KEY=...
   npx supabase functions deploy omdb-proxy
   npx supabase functions deploy gemini-recommend
   npx supabase functions deploy trailer-lookup
   ```
5. `npm run dev` and open the printed link.

If Gemini reports a model error, set a current model name: `npx supabase secrets set GEMINI_MODEL=<name>`.

## How content works (OMDb limits)
OMDb has no trending, top-rated, upcoming or language endpoints, so:
- Homepage rows, Movies, Series and language pages come from **curated lists** (`curated_lists` table: real IMDb IDs you edit).
- Language is read from each title's OMDb `Language` field.
- **Upcoming** tracks only the IMDb IDs you add to the `upcoming` row; a title is never shown as upcoming once its release date has passed.
- Search is by title only. Genre, language and rating filters apply to the titles found.
- Not available without another data source: cast photos, backdrops, trailers (we link a YouTube search), user reviews, similar titles, search by actor/director.
- OMDb free tier is about 1000 calls/day; details are cached in the browser for 7 days.

## Trailers
Hovering a poster (mouse), tapping its play button (touch), the homepage hero and the details page play a muted official trailer.
1. The app reads the `trailers` table first. 2. If there is no row, the `trailer-lookup` function searches YouTube once, verifies the video, and saves it.
A found video is only accepted if it is embeddable and public, 30s-6min long, its title is "<title> ... trailer" with no fan/reaction/clip/song words, its year matches, and the channel is a known studio, distributor or streamer (or matches the film's production company).
Add more trusted channels with `npx supabase secrets set TRAILER_CHANNEL_ALLOWLIST="channel one,channel two"`.
You can also add a trailer by hand in the `trailers` table (`source = manual`, `status = ok`), or hide one with `status = blocked`.
YouTube search costs 100 quota units (free: 10,000/day), so results (including "none", re-checked after 7 days) are cached.
If a trailer is missing or fails, the poster/backdrop stays on screen.

## AI Cinema
Gemini suggests titles as structured JSON. The app validates the JSON, then verifies every title (name, year, type, language) against OMDb. Unverifiable suggestions are hidden. IMDb ratings are official; the "AI match" score is generated by Gemini and labelled as such.

## Security notes
- Never commit `.env` (it is in `.gitignore`).
- Row Level Security limits every user table to the owner's rows.
- The Edge Functions currently accept any caller with your anon key, so a visitor could use your Gemini/OMDb quota. Before a public launch, require login in the functions or add rate limiting.
